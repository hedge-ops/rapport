## [0.1.0] - 2026-04-27

Initial release.

- `OutputBuilder` for fluent markdown output: headings, key-value fields,
  conditional and optional fields.
- `ReportTable` and `Column` for tabular markdown output.
- `truncate` helper for tidy column values.
