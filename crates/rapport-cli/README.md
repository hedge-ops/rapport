# rapport-cli

How do we wrap `clap` to build a pit of success around making command-line
tools that humans and agents both love?

## Status

This `0.0.x` release reserves the name on crates.io while the API is being
designed. The vision and progress live in the
[workspace README](https://github.com/hedge-ops/rapport).

There's nothing useful to depend on yet — pin this version only if you want
to be polite to your future self.
