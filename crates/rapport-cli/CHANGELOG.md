# Changelog

All notable changes to `rapport-cli` are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this crate
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.1.0] - 2026-05-02

### Added

- Added typed argument parsing via the `Argument` trait.
- Added validated arguments via the `ValidatedArgument` trait.
- Added `RepositoryPath` and filesystem-backed directory validation.
- Added parser routing for run invocations, top-level help, and verb help.
- Added test filesystem support for argument validation tests.

## [0.0.1] - 2026-04-27

Name-reservation release. No functionality yet.
