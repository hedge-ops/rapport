# Resume an Interrupted Integration Safely

## Intent

A developer or agent should be able to continue integration after interruption
without duplicating commits, branches, pull requests, or merges.

## Scenarios

### Resume Recorded Integration

_Given_ integration stopped after a durable local or remote side effect
_When_ the developer retries it
_Then_ Rapport reconciles recorded and observed repository state
_And_ resumes the same integration from its last safe transition

### Side Effect Already Completed

_Given_ a commit, push, pull request, check, or merge completed before Rapport
recorded the next transition
_When_ integration resumes
_Then_ Rapport recognizes the matching identity
_And_ does not repeat the completed side effect

### Integration Identity Is Ambiguous

_Given_ the branch, commit, pull request, or target state no longer has one safe
interpretation
_When_ integration resumes
_Then_ Rapport refuses to guess
_And_ reports the conflicting identities
_And_ provides a validated recovery path

### Pull Request Head Changes during Integration

_Given_ the pull request head changes after proof was recorded
_When_ integration resumes
_Then_ Rapport does not force-push or resolve the change automatically
_And_ returns the changed candidate to Develop and explicit Integration update
for current build proof
_And_ requires current Build and independent Review proof for the updated
candidate before merge

### Target Advances during Integration

_Given_ the target branch advances without changing the pull request head
_When_ integration resumes
_Then_ Rapport reports the target advancement
_And_ retains exact-head Build and Review proof
_And_ reevaluates observed checks and mergeability
_But_ does not derive acceptance policy from GitHub branch rules

### Cancel an Owned Integration

_Given_ Rapport can prove the open pull request belongs to active Work
_When_ the developer cancels with a reason
_Then_ Rapport closes the pull request and deletes its same-repository remote
source branch
_And_ records completed side effects so cancellation can resume
_And_ preserves the local branch, Work, Tasks, and proof

### Resume Merge Completion

_Given_ merge submission or post-merge cleanup was interrupted
_When_ the developer completes integration again
_Then_ Rapport does not submit a recorded in-flight merge twice
_And_ reconciles a confirmed matching squash merge
_And_ finishes only missing branch deletion and Work archival
